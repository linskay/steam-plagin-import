# Steam Epic Sync

Легковесная C# утилита для автоматической синхронизации библиотеки **Epic Games Store** с клиентом **Steam**, а также для умного управления фоновыми процессами EGS во время игры.

---

## Основные возможности

* **Автоматический импорт**: Находит установленные игры Epic Games и добавляет их в Steam в качестве сторонних игр (с оригинальными иконками и вычислением корректного Steam AppID).
* **Умное управление ресурсами**: Запускает Epic Games Launcher в фоновом/тихом режиме только на время сессии. После закрытия игры полностью завершает все фоновые процессы Epic (`EpicGamesLauncher.exe`, `EpicWebHelper.exe`), освобождая оперативную память и процессорное время.
* **Современный интерфейс**: Панель управления на WPF с темной темой и полупрозрачным дизайном (эффект акрила/стекла) для удобной настройки и мониторинга.
* **Низкое потребление ресурсов**: Утилита написана на нативном C# (.NET Framework 4.X), работает без сторонних зависимостей и расходует всего 5–15 МБ ОЗУ в свернутом режиме.
* **Работа из трея**: Удобное меню в системном трее для быстрой синхронизации, настройки автозапуска с Windows и открытия дашборда.

---

## Установка и использование

1. Перейдите в раздел **Releases** на GitHub и скачайте последнюю версию архива `SteamEpicSync.zip`.
2. Распакуйте архив в удобную постоянную папку (программе необходимы файлы `SteamEpicSync.exe` и `MainWindow.xaml` в одной директории).
3. Запустите `SteamEpicSync.exe`.
4. Нажмите **Синхронизировать сейчас** в открывшейся панели (или выберите этот пункт в меню трея).
5. Перезапустите клиент Steam. Игры из Epic Games Store появятся в вашей библиотеке Steam.

---

## Параметры командной строки (CLI)

* `SteamEpicSync.exe --sync-silent` — выполняет синхронизацию в фоновом режиме без открытия окон и завершает работу.
* `SteamEpicSync.exe --launch "<AppName>"` — запускает указанную игру Epic Games, отслеживает её состояние и закрывает EGS после выхода из игры.

---

## Сборка из исходников

Для сборки проекта на Windows не требуется установка дополнительных SDK или компиляторов. Достаточно запустить командный файл сборки в папке проекта:

```cmd
build.bat
```

Скрипт автоматически найдет встроенный компилятор `.NET Framework` и соберет проект в один исполняемый файл `SteamEpicSync.exe`.
