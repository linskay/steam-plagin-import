## 🚀 Основные возможности

* **🔄 Автоматический импорт**: Находит установленные игры Epic Games и добавляет их в Steam в качестве сторонних игр (с оригинальными иконками и вычислением корректного Steam AppID для поддержки оверлея).
* **🧠 Умное управление ресурсами**: Запускает Epic Games Launcher в фоновом/тихом режиме только на время сессии. После закрытия игры полностью завершает все фоновые процессы Epic (`EpicGamesLauncher.exe`, `EpicWebHelper.exe`), освобождая оперативную память и процессорное время.
* **🎨 Современный интерфейс**: Панель управления на WPF с темной темой и полупрозрачным дизайном (эффект акрила/стекла) для удобной настройки и мониторинга.
* **⚡ Низкое потребление ресурсов**: Утилита написана на нативном C# (.NET Framework 4.X), работает без тяжелых внешних зависимостей и расходует всего 5–15 МБ ОЗУ в фоновом режиме.
* **📥 Работа из трея**: Удобное меню в системном трее для быстрой синхронизации, настройки автозапуска с Windows и открытия дашборда.

## 📦 Установка и использование

1. Перейдите в раздел **[Releases](https://github.com/linskay/steam-plagin-import/releases/latest)** и скачайте файл `SteamEpicSync.exe`.
2. Поместите его в любую удобную папку на вашем компьютере.
3. Запустите `SteamEpicSync.exe`.
4. Нажмите кнопку **Синхронизировать сейчас** в интерфейсе панели (или выберите этот пункт в меню трея).
5. Полностью перезапустите Steam. Игры из Epic Games Store появятся в вашей библиотеке Steam.

## 💻 Параметры командной строки (CLI)

Утилита поддерживает автоматизацию через аргументы запуска:

| Аргумент | Описание |
| :--- | :--- |
| `--sync-silent` | Выполняет синхронизацию библиотеки в фоновом режиме без открытия окон и завершает работу. |
| `--launch "<AppName>"` | Запускает указанную игру Epic Games, отслеживает её состояние и закрывает EGS после выхода из игры. |

## 🛠️ Сборка из исходников

Для компиляции проекта на Windows не требуется установка сторонних SDK или компиляторов. Сборка выполняется стандартным компилятором .NET:

1. Откройте терминал в папке проекта.
2. Запустите скрипт компиляции:
   ```cmd
   build.bat
   ```

Скрипт скомпилирует исходный код в исполняемый файл `SteamEpicSync.exe` в корневой папке проекта.

## Исправленная версия: библиотека Epic и оформление Steam

1. Запустите `SteamEpicSync.exe` из постоянной папки (не перемещайте EXE после импорта).
2. Нажмите **Подключить аккаунт**, затем **Открыть вход Epic Games**.
3. Войдите в Epic в обычном браузере. На итоговой странице скопируйте `authorizationCode` или весь JSON в окно утилиты и нажмите **Подключить**. Код одноразовый; при ошибке получите новый. Не отправляйте этот код другим людям.
4. Полностью закройте Steam через **Steam → Выход**, затем нажмите **Синхронизировать сейчас**. Утилита останется в трее, когда Steam закрыт.
5. Откройте Steam: игры появятся как сторонние, с коллекцией **Есть в EGS**. Импортируются принадлежащие аккаунту игры для Windows, включая неустановленные; DLC, редакторы и плагины исключаются.

Для неустановленной игры кнопка запуска в Steam открывает Epic Launcher, через который можно установить игру. Сохранённый кэш содержит идентификаторы для запуска и URL обложек. При сбое сети используется кэш; ранее импортированные игры автоматически не удаляются.

Обложки Epic сохраняются в `userdata/<id>/config/grid` в портретном, горизонтальном и hero-формате. Рамка и плашка **EPIC GAMES** нанесены на сами изображения. Если обложка отсутствует или недоступна, создаётся карточка с названием; при следующей синхронизации загрузка повторяется. Уже существующие пользовательские изображения не перезаписываются. Отдельный значок магазина в штатном интерфейсе Steam утилита не добавляет.

Существующий `shortcuts.vdf` сохраняется как `shortcuts.vdf.bak` перед заменой. Повреждённый VDF блокирует запись. Для полного удаления управляемых ярлыков используйте штатную кнопку удаления при закрытом Steam.

Проверки: `powershell -NoProfile -ExecutionPolicy Bypass -File tests/run.ps1`. Тесты работают в отдельной временной папке и не меняют профиль Steam.

Протокол получения принадлежащих аккаунту Windows-игр и OAuth-клиент сверены с исходниками Legendary: https://github.com/derrod/legendary/blob/master/legendary/api/egs.py . Это неофициальный API Epic; изменение API может потребовать обновления утилиты.

Миниатюры в боковом списке Steam: для каждой игры создаётся отдельная иконка 64×64 ICO из обложки и сохраняется в поле icon ярлыка. Это работает и для неустановленных игр.

Коллекция «Есть в EGS» создаётся и обновляется кодом синхронизации. Для текущего формата Steam обновляется cloudstorage namespace 1, а ключ коллекции помечается изменённым. Список переключается с группировки по недавней активности на коллекции; посторонние коллекции сохраняются. Перед записью настроек создаются файлы .SteamEpicSync.bak.

## Модуль интерфейса Steam

Модуль Millennium реализован в `millennium-plugin/`. Он подсвечивает установленные игры Epic синим, показывает описание и данные разработчика на странице импортированной игры, а на совпавших карточках и страницах магазина Steam добавляет **In Epic Games Library**.

Утилита проверяет библиотеку, манифесты установки, описания и соответствия Steam только при синхронизации. После установки или удаления игры снова выполните синхронизацию с закрытым Steam. Модуль читает один снимок при запуске клиента, а дальше реагирует только на отрисовку интерфейса; сетевых запросов, таймеров и сканирования диска в модуле нет.

Описание и оформление работают для сторонних ярлыков и не выдают игру за покупку в Steam. Для неоднозначных или отсутствующих совпадений в каталоге Steam плашка не показывается. Полный установочный ZIP должен содержать EXE и папку `millennium-plugin`; одиночный EXE продолжает импортировать игры, но не устанавливает среду Millennium.

Установка, сборка и проверки описаны в `millennium-plugin/README.md`. Millennium — отдельная зависимость; установщик проверяет SHA-256 официального архива. Снимки лежат в `Steam/config/SteamEpicSync/<accountID>.json`, без токенов Epic и путей установки игр.
